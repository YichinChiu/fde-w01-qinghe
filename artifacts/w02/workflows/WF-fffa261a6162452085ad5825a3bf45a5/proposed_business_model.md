# W2 业务模型说明：首版业务模型（重点经营会员与试点支持）

本模型保存为 `docs/w02/business_model.md`，用于核实第一阶段“需要重点经营的会员”所需的业务认识。

## 1. 要回答的问题与范围

### 1.1 当前希望业务模型帮助理解的内容
1. **重点经营会员对象界定**：青禾会员体系的基本划分，以及如何界定“消费下降/需要重点经营”的会员。
2. **关键指标口径与现状**：复购率、活跃会员、老会员及“80万”会员规模的定义、负责方与统计依据。
3. **角色分工与交接关系**：管理层（沈总）、IT系统（老周）、运营（小林）、门店（陈姐）的职责边界、数据交接及转介循环。
4. **第一阶段试点范围与授权边界**：助手的输入输出边界、前置清单、权限限制（哪些动作未获授权）。

### 1.2 暂不纳入的内容
- 不纳入具体的复购率计算公式或活跃会员时间窗口（公司口径尚未定义）。
- 不把“80万活跃会员”作为既定会员规模（仅为发起人提法，无统计支撑）。
- 不把小林手工维护的 Excel 账本当作公司统一口径或交付数据。
- 不裁决上一个智能营销项目失败的单一原因（各方观察不同，保留并列）。

## 2. 对象、属性与关系

### 2.1 会员（Member）
- **对象定义**：青禾会员体系中的顾客实体。三方陈述一致确认划分为两类（CLM-001-0010/CLM-001-0017/CLM-002-0024/CLM-003-0039）：
  - **付费会员卡会员**：持有付费权益卡。
  - **免费注册会员**：免费注册建立关系的会员。
- **建模选择与规则**：
  - 会员统计与运营必须将两类分开，不可混为一谈。
  - “重点经营”对象小林主张两类都要看但要分开看，优先级需看核实后的数量与复购数据（CLM-003-0042）。两类会员在权益、触达及活动上的具体区分待查实际记录（CLM-003-0041）。
- **未知项**：两类会员在收银现场的识别方式是否一致目前未知（CLM-001-0010/CLM-001-0018）。

### 2.2 订单与渠道（Order & Channel）
- **渠道划分**：分为**线上渠道**与**门店渠道**（老周 CLM-002-0025，小林 CLM-003-0039）。
- **订单与会员关联（关键待核数据前提）**：
  - 线上订单通常具备明确会员账户绑定。
  - **门店订单归属未知**：若顾客在门店结账未报会员身份，消费是否记入会员名下，陈姐与老周均表示不掌握（CLM-001-0009/CLM-002-0021形成转介循环）。
  - **影响**：若门店消费未归属，系统将产生“消费下降”的假象，直接影响找人准确性。

### 2.3 门店（Store）
- **职责定位**：活动执行与会员咨询配合方，负责让员工了解权益说明、接待会员咨询、配合注册与执行，并反馈现场问题（陈姐 CLM-001-0005/CLM-001-0006）。
- **试点参与状态**：目前**不是**名单使用方；第一阶段门店是否参与、名单是否下发“未定，待试点方案议定”（沈总 CLM-001-0003）。陈姐对回头客有变化感知但无统计数据（CLM-001-0011），陈姐不掌握旧项目在门店的具体情况（CLM-001-0012）。

### 2.4 运营活动（Campaign）
- **规则与适用范围**：活动具有明确的适用渠道与参与门店范围；会员持线上活动咨询时，门店必须先核对适用范围再答复，不能默认线上可见即可在所有门店执行（陈姐 CLM-001-0007）。
- **名单下发规则**：总部是否随活动下发具体名单供回访邀约，小林表示视具体活动安排而定，无固定流程（CLM-002-0023/CLM-001-0008）。

### 2.5 运营指标与规模（Metrics & Scale）
- **复购率（Repurchase Rate）**：四方均无法指出“项目组”是谁，复购率口径处于“口径未定、牵头方缺位”状态（CLM-001-0001/CLM-001-0013/CLM-001-0014/CLM-002-0022/CLM-002-0026/CLM-003-0038）。复购连续四季下滑仅为转述，下滑原因保持未知。
- **活跃会员 / 老会员**：目前青禾无明确公司规定，小林亦无固定习惯，不可代为定义（CLM-003-0040）。
- **80万活跃会员**：仅为沈总按个人说法提出的指标，无统计依据，不作为规模数据写入模型（CLM-001-0002/CLM-002-0024）。

## 3. 规则、条件与候选动作

### 3.1 规则与适用条件
1. **试点方案前置清单（老周与沈总清单合并）**：在申请取数与讨论试点前，我方项目组必须书面明确：
   - 要验证的业务问题；
   - 准备覆盖的会员类别（付费卡 / 免费注册）与订单渠道（线上 / 门店）；
   - 数据用途与准备给谁看；
   - 需要谁配合的清单；
   - 已有依据、待核项与阶段结果观察方式。
2. **数据守门与安全规则**：老周负责检查取数条件，用途或安全要求不清时有权**暂缓接入**；老周无权代为审批数据权限，脱敏样本审批手续待核实（CLM-002-0028）。老周真实顾虑为需求变动导致取数返工（CLM-002-0029/CLM-002-0030）。
3. **活动执行核对规则**：活动适用范围必须由门店执行前与运营核对确认（CLM-001-0006/CLM-001-0007）。

### 3.2 候选动作与授权边界（非已实现能力，严禁自动执行）
- **候选动作**：
  - 动作 1：基于核实后的数据，输出消费下降会员识别名单。
  - 动作 2：随名单输出推荐运营动作及说明建议依据（减轻小林整理名单与核对信息的负担，回应 CLM-003-0043）。
- **授权边界与严格限制**：
  - **受众范围**：第一阶段名单和建议仅输出给小林（业务人员）审阅（沈总 W1 MSG-00671）。
  - **人工确认机制**：目标人群与执行方案**必须经业务人员确认**后方可推进（小林 CLM-003-0044）。
  - **禁止自动执行**：**严禁助手自动发券、自动联系会员、自动修改业务系统记录**（小林 CLM-003-0044）。

## 4. 依据与建模选择

1. **对象划分充分性**：会员分付费与免费两类、订单分线上与门店，得到了老周、小林、陈姐的一致陈述，作为核心对象结构写入。
2. **负责方缺位建模**：“项目组”在四方访谈中均确认无具体团队对应，属于“负责方缺位”。两边对不上时由沈总召集相关人定口径，但召集后由谁最终裁决未说明，模型不赋予沈总终审设定。
3. **工作账与统一口径解耦**：小林手工 Excel 是个人工作记录，不能作为公司口径或交付数据。第一阶段取数必须通过老周四步配合流程进行。
4. **门店数据风险控制（我方核查计划）**：针对收银归属未知，制定核查策略：取得脱敏样本后，首先测算门店订单中带会员标识的比例，再评估是否将门店渠道纳入消费下降识别。
5. **试点设计启示**：书面固定范围与用途以消除老周返工顾虑；以减少实际操作步骤衡量助手价值，避免重蹈旧项目“多了三步”覆辙。

## 5. 未知、分歧与转介关系

### 5.1 转介关系与循环
1. **收银识别与订单归属循环**：
   - 陈姐表示不掌握，转介给老周和小林；
   - 老周表示不掌握，转介给陈姐；
   - 形成闭环，且小林尚未被询问该项。下一步向小林核实。
2. **复购率负责方循环/缺位**：
   - 小林、陈姐、老周均转介给“项目组”；
   - 老周转介运营，小林转介老周与项目组；
   - 沈总确认无法认定，需双方先自证依据，对不上由沈总召集。

### 5.2 核心业务未知项
1. 会员规模：80万活跃会员的统计来源及分类归属未知。
2. 收银规则：未报会员身份的消费是否补记、两类会员收银识别差异未知。
3. 脱敏审批：数据取样审批责任人与流程未知。
4. 试点覆盖：门店是否参与、名单是否下发待试点方案议定。
5. 复购下滑原因：无任何角色给出客观数据依据，保持未知。
