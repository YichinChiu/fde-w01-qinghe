优先整理访谈者列出的 focus_questions 相关陈述，并保留理解这些陈述所需的背景。
区分客户对现状的说法、个人观点和目标、尚待核实的问题。一个条目尽量只表达一项可核对的主张。
同一个术语在不同角色、时间或范围下可能含义不同，保留原文限定，不自行统一。
若原文只提出问题而没有答案，不把问题改写成已经存在的业务规则。
一条候选只对应一位受访者。多人说法相同时分别列出，不合并不同角色；在 qualifiers 第一项写“主体：<role_id>”。
受访者说不掌握、说不准、需要查记录或不能凭印象时，保留为未知：在 qualifiers 写“未知：<哪项内容>；核实对象：<受访者指向的人或记录，未指出写未指出>”，不改写为“没有”“不存在”或“为零”。
受访者把问题转给他人时，在 qualifiers 写“转介：→<对象>”，不把转介写成被转介者已经确认的事实。
受访者对自己说法的限定必须保留在 statement 或 qualifiers，例如“只是例子”“不能当作原因”“不是公司口径”“不能当交付数据”“不代表已交付”“不表示已获批”；带限定的说法不得提升为公司规则。
受访者描述的工作步骤、前置条件和希望看到的内容清单，逐项完整保留，不只摘结论。受访者逐条确认访谈者复述的消息，可作为补充证据引用；访谈者的复述本身不是受访者陈述。
