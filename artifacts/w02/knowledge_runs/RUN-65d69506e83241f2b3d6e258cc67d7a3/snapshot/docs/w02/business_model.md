# W2 业务模型说明：首版业务模型（重点经营会员与试点支持）

本模型保存为 `docs/w02/business_model.md`，用于核实第一阶段“需要重点经营的会员”所需的业务认识。

## 1. 要回答的问题与范围

### 1.1 当前希望业务模型帮助理解的内容
1. **重点经营会员对象界定**：青禾会员体系的基本划分，以及如何界定“消费下降/需要重点经营”的会员。
2. **关键指标口径与现状**：复购率、活跃会员、老会员及“80万”会员规模的定义、负责方与统计依据。
3. **角色分工与交接关系**：管理层（沈总）、IT系统（老周）、运营（小林）、门店（陈姐）的职责边界、数据交接及转介循环。
4. **第一阶段试点范围与授权边界**：助手的输入输出边界、前置清单、权限限制（哪些动作未获授权）。

### 1.2 暂不纳入的内容
- 不纳入具体的复购率计算公式或活跃会员时间窗口（公司口径尚未定义）。
- 不把“80万活跃会员”作为既定会员规模（仅为发起人提法，无统计支撑）。
- 不把小林手工维护的 Excel 账本当作公司统一口径或交付数据。
- 不裁决上一个智能营销项目失败的单一原因（各方观察不同，保留并列）。

## 2. 对象、属性与关系

### 2.1 会员（Member）
- **对象定义**：青禾会员体系中的顾客实体。三方陈述一致确认划分为两类（陈姐 CLM-001-0010，老周 CLM-001-0017，小林 CLM-002-0024/CLM-003-0039）：
  - **付费会员卡**
  - **免费注册会员**
- **建模选择与规则**：
  - 会员统计与运营必须将两类分开，不可混为一谈。
  - “重点经营”对象小林主张两类都要看但要分开看，优先级需看核实后的数量与复购数据（CLM-003-0042）。
- **未知项**：
  - 两类会员在权益、触达方式、活动安排上具体怎么分开做，口径待查实际记录（CLM-003-0041）。
  - 两类会员在收银现场的识别方式是否一致目前未知（陈姐 CLM-001-0010，老周 CLM-001-0018）。

### 2.2 订单与渠道（Order & Channel）
- **渠道划分**：分为**线上渠道**与**门店渠道**（老周 CLM-002-0025 与小林 CLM-003-0039 两方说法）。陈姐所提线上/门店指活动适用范围（CLM-001-0007/MSG-01865），非订单渠道。
- **订单与会员关联（关键待核数据前提）**：
  - **线上订单与会员关联未知**：线上订单与会员的具体关联方式受访者均未说明，属于未知。
  - **门店订单归属未知**：顾客在门店结账未报会员身份时消费是否记入会员名下，陈姐与老周均表示不掌握（CLM-001-0009/CLM-002-0021形成转介循环）。
  - **影响与核查计划**：若订单无法准确归属会员，系统将产生“消费下降”假象，直接影响找人准确性。线上与门店订单的会员归属均列为待核数据前提；取得脱敏样本后，首先测算订单中带会员标识的比例，再评估将哪些渠道纳入消费下降识别（这是我方的核查计划，非客户已同意做法）。

### 2.3 门店（Store）
- **职责定位**：活动执行与会员咨询配合方，负责让员工了解权益说明、接待会员咨询、配合注册与执行，并反馈现场问题（陈姐 CLM-001-0005/CLM-001-0006）。
- **试点参与状态**：第一阶段门店是否参与、名单是否下发到门店并回访，沈总在 W2 说“目前还没定”，属试点方案要议的范围（沈总 MSG-01884，CLM-001-0003）。陈姐本人只说她不掌握总部会不会随活动下发名单（MSG-01869/01875），没有说门店是或不是名单使用方。
- **建模选择（我方，非客户说法）**：本轮模型暂不把门店写成名单接收方，门店只作为活动执行与会员咨询方；这是因为门店参与尚未议定，不代表客户已排除门店。
- **门店的其他陈述**：陈姐对回头客有变化感知但无统计数据（CLM-001-0011）；陈姐不掌握旧项目在门店的具体情况（CLM-001-0012）。

### 2.4 运营活动（Campaign）
- **规则与适用范围**：活动具有明确的适用渠道与参与门店范围；会员持线上活动咨询时，门店必须先核对适用范围再答复，不能默认线上可见即可在所有门店执行（陈姐 CLM-001-0007）。
- **名单下发规则**：总部是否随活动下发具体名单供回访邀约，小林表示视具体活动安排而定，无固定流程（CLM-002-0023/CLM-001-0008）。

### 2.5 运营指标与规模（Metrics & Scale）
- **复购率（Repurchase Rate）**：四方均无法指出“项目组”是谁，复购率口径处于“口径未定、牵头方未确定”状态（CLM-001-0001/CLM-001-0013/CLM-001-0014/CLM-002-0022/CLM-002-0026/CLM-003-0038）。“连续四个季度下滑”仅为转述，下滑原因保持未知（沈总 W1 MSG-00654 的“会员老化”为个人推断，未经数据验证）。
- **活跃会员 / 老会员**：目前青禾无明确公司规定，小林亦无固定习惯，不可代为定义（CLM-003-0040）。
- **80万活跃会员**：仅为沈总按个人说法提出的指标，无统计依据，不作为会员规模写入模型（CLM-001-0002/CLM-002-0024）。

## 3. 规则、条件与候选动作

### 3.1 规则与适用条件
1. **试点方案前置清单（老周与沈总清单合并）**：在申请取数与讨论试点前，我方项目组必须书面明确：
   - 要验证的业务问题；
   - 准备覆盖的会员类别（付费卡 / 免费注册）与订单渠道（线上 / 门店）；
   - 数据用途与准备给谁看；
   - 需要谁配合的清单；
   - 已有依据、待核项与阶段结果观察方式。
2. **数据守门与安全规则**：老周负责检查取数条件，用途或安全要求不清时有权**暂缓接入**；老周无权代为审批数据权限，脱敏样本审批手续待核实（CLM-002-0028）。老周真实顾虑为需求变动导致取数返工（MSG-01860）。
3. **活动执行核对规则**：门店接到活动后先核对面向哪些会员、哪些门店参与、门店要做什么；会员拿线上活动来问时先核对适用范围再答复；执行中有不清楚的找运营核对（陈姐 CLM-001-0006/CLM-001-0007）。“不清楚时找运营”是陈姐描述的做法，不是每次执行前都必须经运营确认的硬性规则。

### 3.2 候选动作与授权边界（非已实现能力，未获自动执行授权）
- **候选动作**：
  - 动作 1：基于核实后的数据，输出消费下降会员识别名单。
  - 动作 2：随名单输出推荐运营动作及说明建议依据（减轻小林整理名单与核对信息的负担，CLM-003-0043）。
- **授权边界与严格限制**：
  - **受众范围（同一人在不同时间的两种说法，均保留）**：沈总在 W1 同意“第一阶段先只给小林看名单和建议，不直接打标签发券或改系统”（W1 MSG-00671）；沈总在 W2 又说第一阶段覆盖到哪、门店要不要参与、名单是否下发到门店“目前还没定”，方案拿出来再议（MSG-01884）。当前可确定的只有：名单和建议至少给小林看；是否同时下发门店未定，不能回答为“不能下发”或“可以下发”。
  - **人工确认机制**：目标人群与执行方案**必须经业务人员确认**后方可推进（小林 CLM-003-0044）。
  - **未授权自动执行**：小林原话是“我没有授权它自动发券、联系会员或改记录”（MSG-01847，CLM-003-0044）；沈总 W1 也同意第一阶段不直接打标签、发券或改系统（W1 MSG-00671）。引用时用“未授权”，不要写成客户说过“严禁”。

## 4. 依据与建模选择

1. **对象与渠道划分依据**：
   - 会员分付费会员卡与免费注册会员两类，为三方说法（陈姐、老周、小林），作为核心对象结构写入。
   - 订单分线上与门店两个渠道，为两方说法（老周 MSG-01854、小林 MSG-01843）；陈姐所提线上/门店指活动适用范围。
2. **负责方缺位建模**：四方均无法指出“项目组”具体是谁。两边对不上时由沈总召集相关人定口径和牵头方，但召集后由谁最终裁决未说明，模型不赋予沈总终审设定。
3. **工作账与统一口径解耦**：小林手工 Excel 是个人工作记录，不能作为公司统一口径或交付数据。第一阶段取数必须通过老周四步配合流程进行。
4. **订单数据风险控制（我方核查计划）**：针对线上与门店订单与会员归属均未知的情况，取得脱敏样本后，首先测算各渠道订单中带会员标识的比例，再评估消费下降识别范围。
5. **试点设计启示（我方判断）**：试点方案须书面固定范围与用途（回应老周的返工顾虑）；并以小林的实际操作步骤衡量助手是否减少而非增加操作（回应旧项目“多了三步”）。

## 5. 未知、分歧与转介关系

### 5.1 转介关系与循环
1. **收银识别与订单归属循环**：
   - 陈姐表示不掌握，转介给老周和小林（MSG-01871）；
   - 老周表示不掌握，转介给陈姐（MSG-01902）；
   - 形成闭环；陈姐同时转介小林，小林尚未被询问该项。下一步向小林核实。
2. **复购率转介关系与缺位**：
   - 沈总（W1 MSG-00667）指向老周、小林；
   - 小林（MSG-01851）指出复购率口径要找项目组核实，不是老周那边（老周管系统）；
   - 老周（MSG-01856）指出口径要项目组核实，不替业务定口径（老周 MSG-01900 中与运营确认会员范围指的是核实会员数）；
   - 陈姐（MSG-01875）亦指出复购率计算口径要项目组核实；
   - 四方都指不出“项目组”是谁，构成负责方缺位。

### 5.2 核心业务未知项
1. 会员规模：80万活跃会员的统计来源及分类归属未知。
2. 订单关联规则：线上订单如何绑定会员，门店未报会员身份消费是否记入会员名下，两类会员收银识别差异均未知。
3. 脱敏审批：数据取样审批责任人与流程未知。
4. 试点覆盖：门店是否参与、名单是否下发待试点方案议定。
5. 复购下滑原因：无客观数据依据，保持未知。
